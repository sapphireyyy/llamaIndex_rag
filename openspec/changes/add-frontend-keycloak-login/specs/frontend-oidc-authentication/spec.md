## Purpose

定义浏览器前端与 Keycloak OIDC 身份提供方之间可验证、可恢复且默认拒绝的认证会话，并确保认证主体、访问令牌与租户边界在所有页面和请求通道中保持一致。

## ADDED Requirements

### Requirement: 受保护页面必须等待认证状态确定
前端 SHALL 在认证状态确定前阻止租户发现和其他受保护业务请求，并 SHALL 为未认证、认证中、已认证和认证失败提供互斥的页面状态。

#### Scenario: 未认证用户打开应用
- **WHEN** 用户在没有有效登录会话的情况下打开任一受保护页面
- **THEN** 前端显示登录入口，且不发送租户发现或其他受保护 API 请求

#### Scenario: 应用正在恢复登录会话
- **WHEN** 前端正在处理 OIDC 回调或检查既有身份提供方会话
- **THEN** 前端显示明确的认证中状态，且不会短暂渲染其他用户或未授权租户的数据

#### Scenario: 已认证用户打开应用
- **WHEN** 前端确认当前 OIDC 会话和访问令牌有效
- **THEN** 前端加载当前主体可发现的租户并继续进入应用

### Requirement: 登录必须使用带 PKCE 的授权码流程
前端 MUST 通过 Keycloak OIDC Authorization Code Flow with PKCE 发起交互式登录，MUST 校验回调关联状态和令牌声明，并 MUST NOT 使用资源所有者密码模式或在浏览器中持有客户端密钥。

#### Scenario: 用户发起登录
- **WHEN** 未认证用户选择登录
- **THEN** 前端生成新的 PKCE、state 和 nonce 上下文，并将用户重定向到配置的 Keycloak 授权端点

#### Scenario: 有效登录回调
- **WHEN** Keycloak 返回与当前登录尝试匹配的授权码、state 和有效令牌声明
- **THEN** 前端建立认证会话并恢复登录前计划访问的应用位置

#### Scenario: 回调完整性校验失败
- **WHEN** 回调缺少必要参数，或 state、nonce、issuer、audience、签发时间、过期时间中的任一校验失败
- **THEN** 前端拒绝建立会话、清除本次临时认证状态，并显示可重新登录的安全错误

### Requirement: OIDC 配置必须与部署公开地址一致
前端 SHALL 从公开运行时配置获得 OIDC issuer、公共客户端标识、redirect URI、post-logout redirect URI 和 scopes。部署环境 MUST 在 Keycloak 中精确登记实际前端 Origin 与重定向地址，且任何前端公开配置 MUST NOT 包含客户端密钥或其他机密。

#### Scenario: 使用 Docker 本地页面登录
- **WHEN** 用户从 Docker 暴露的前端公开地址发起登录
- **THEN** Keycloak 接受该 Origin 和回调地址，并将浏览器返回同一公开前端地址

#### Scenario: 配置缺失或不一致
- **WHEN** 必需 OIDC 配置缺失，或当前页面 Origin 不在允许的重定向和 Web Origin 范围内
- **THEN** 前端停止受保护请求并显示不包含敏感配置值的认证配置错误

### Requirement: 所有受保护请求必须携带当前访问令牌
前端 MUST 通过统一认证边界向所有受保护 API 请求附加当前主体的 `Authorization: Bearer <access_token>`，包括普通 JSON 请求、文件上传、预览、下载和流式问答。健康检查等明确公开的端点 SHALL NOT 要求访问令牌。

#### Scenario: 调用普通受保护接口
- **WHEN** 已认证用户加载租户、知识空间、助手、质量或管理数据
- **THEN** 每个请求携带当前有效访问令牌以及适用的租户边界头

#### Scenario: 发起流式问答
- **WHEN** 已认证用户提交流式问答请求
- **THEN** 流式请求使用与普通请求相同的当前访问令牌和租户边界，且整个响应只绑定该认证主体

#### Scenario: 获取受保护文件
- **WHEN** 已认证用户预览或下载受保护文档
- **THEN** 文件请求通过能够附加访问令牌的认证通道完成，而不是依赖无认证的直接资源链接

### Requirement: 令牌生命周期必须可恢复且限制重试
前端 SHALL 在访问令牌过期前续期或重新获得有效令牌，并 SHALL 对因令牌失效产生的 401 最多进行一次受控恢复重试。续期失败 MUST 终止当前认证会话，且并发请求 MUST NOT 各自触发重复续期。

#### Scenario: 令牌即将到期
- **WHEN** 已认证用户发起请求且访问令牌进入配置的到期保护窗口
- **THEN** 前端先完成一次共享的令牌续期，再使用新令牌发送等待中的请求

#### Scenario: API 返回认证失败
- **WHEN** 受保护请求使用当前令牌返回 401
- **THEN** 前端在一次成功续期后仅重试原请求一次，避免无限重试循环

#### Scenario: 续期或重新认证失败
- **WHEN** Keycloak 会话已失效、续期被拒绝或身份提供方不可用
- **THEN** 前端清除本地认证和租户状态，显示会话已失效提示，并允许用户重新登录

#### Scenario: API 返回授权失败
- **WHEN** 已认证请求返回 403
- **THEN** 前端显示权限不足而不清除有效登录会话，也不把 403 误判为需要刷新令牌

### Requirement: 退出登录必须清除身份和租户边界
前端 SHALL 同时结束本地认证状态与 Keycloak 单点登录会话，并 MUST 清除当前主体相关的令牌、租户选择、页面缓存和尚未完成的受保护请求。退出后的浏览器历史记录 MUST NOT 恢复受保护内容。

#### Scenario: 用户主动退出登录
- **WHEN** 已认证用户选择退出
- **THEN** 前端立即停止受保护请求、清除主体相关状态、请求 Keycloak 结束会话，并返回未认证页面

#### Scenario: 登录主体发生变化
- **WHEN** 浏览器在退出后或会话恢复时认证为不同 OIDC subject
- **THEN** 前端不复用前一主体的租户选择、查询历史或业务缓存，并重新执行租户发现

### Requirement: 租户选择必须绑定当前认证主体
前端 SHALL 仅允许从当前已验证主体可发现且处于可用状态的租户中选择租户。任何记忆的租户选择 MUST 在主体和最新租户发现结果下重新验证后才可恢复。

#### Scenario: 恢复仍可访问的租户
- **WHEN** 同一认证主体重新进入应用，且记忆的租户仍在最新可发现租户列表中
- **THEN** 前端可恢复该租户并使用它建立后续请求边界

#### Scenario: 记忆的租户不再可访问
- **WHEN** 当前主体已失去记忆租户的成员关系，或租户被暂停、归档或不再返回
- **THEN** 前端清除该选择并要求从当前可访问租户中重新选择，不向旧租户发送业务请求

### Requirement: 浏览器不得持久化或泄露访问令牌
前端 MUST NOT 将访问令牌、刷新令牌或授权码写入 `localStorage`、URL 查询历史、日志、遥测、错误提示或用户可复制诊断信息。页面刷新后的会话恢复 SHALL 依赖受控会话状态或身份提供方会话，而不是长期可读令牌副本。

#### Scenario: 页面刷新
- **WHEN** 已认证用户刷新浏览器页面
- **THEN** 前端通过受控会话恢复流程确认身份，且长期浏览器存储中不存在可读取的访问令牌或刷新令牌

#### Scenario: 认证错误被记录
- **WHEN** 登录、回调、续期或受保护请求失败
- **THEN** 用户提示与诊断信息仅包含稳定错误类别和适用的关联标识，不包含令牌、授权码或敏感声明

### Requirement: 开发认证与 OIDC 模式必须显式隔离
前端和部署配置 SHALL 允许 development/test 环境使用明确启用的开发身份模式，并 MUST 在 staging/production 环境要求 OIDC。开发身份模式不得产生伪造的浏览器令牌，也不得掩盖生产近似环境中缺失的登录联动。

#### Scenario: 开发身份模式启用
- **WHEN** 应用运行于 development/test 且部署显式启用开发认证
- **THEN** 前端可跳过 Keycloak 交互登录，并按开发身份加载页面

#### Scenario: 生产近似环境启动
- **WHEN** 应用运行于 staging/production
- **THEN** 缺失 OIDC 配置或未认证用户不能访问受保护业务数据，系统也不会自动回退到开发身份

### Requirement: 认证界面必须提供清晰且可访问的反馈
前端 SHALL 以中文提供登录、认证中、会话过期、权限不足、身份提供方不可用和配置错误状态，并 SHALL 保证登录、重试和退出操作可通过键盘操作且具有可识别的辅助技术标签。

#### Scenario: Keycloak 暂时不可用
- **WHEN** 登录跳转、会话检查或令牌续期因身份提供方不可用而失败
- **THEN** 前端保留未认证边界，显示可重试提示，并不展示之前主体的受保护内容

#### Scenario: 键盘用户完成登录入口操作
- **WHEN** 键盘或辅助技术用户访问未认证页面
- **THEN** 登录按钮、状态提示和重试操作具有明确名称、焦点顺序和状态反馈
